# Calculadora IRPF autónomos Cataluña

Web estática y gratuita que estima el IRPF de un autónomo residente en Cataluña en 2025 y 2026. Se publica con GitHub Pages en <https://juli2006farres.github.io/calculadora-irpf-autonomos-cataluna/>.

- **Sin servidor ni datos guardados:** el cálculo se hace en el navegador. No hay registro, cookies ni analítica.
- **Mismo cálculo que el servidor MCP:** `irpf/calculo.js` e `irpf/tablas.js` son copias exactas de la compilación de `irpf-pymes-cat-mcp`. Si cambian las tablas, hay que compilar el servidor y volver a copiar esos dos archivos.
- **Enlace al servidor MCP:** la página ofrece el servidor en MCPize, que tiene un plan gratuito.

Es una estimación orientativa y no sustituye a un asesor fiscal.
